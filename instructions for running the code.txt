تعليمات تشغيل مشروع نظام المركز الصحي للدعم التغذوي

========================================

1. ترتيب ملفات المشروع
   ========================================

يجب أن تكون ملفات المشروع مرتبة بالشكل التالي:

```text
المشروع الفصلي/
├── تعليمات التشغيل.txt
└── الكود/
    ├── backend/
    │   └── health_center_project/
    │       ├── manage.py
    │       ├── requirements.txt
    │       ├── .env
    │       ├── health_center/
    │       ├── face_models/
    │       └── media/
    ├── frontend/
    │   └── next-project/
    │       ├── package.json
    │       ├── package-lock.json
    │       ├── src/
    │       └── public/
    └── database/
        └── health_db.sql
```

ملاحظات مهمة:

1. ملف التعليمات يوضع مباشرة داخل مجلد `المشروع الفصلي`.
2. ملف قاعدة البيانات يجب أن يكون داخل:

```text
المشروع الفصلي\الكود\database\health_db.sql
```

3. يجب تضمين ملف `.env` داخل مجلد الباك.
4. يجب تضمين مجلد `media` إذا كانت صور المستفيدين مطلوبة.
5. ليس من الضروري إرسال مجلدي `venv` و`node_modules`؛ سيتم إنشاؤهما على جهاز التشغيل.

========================================
2. البرامج المطلوبة
===================

يجب تثبيت البرامج التالية:

1. MySQL Server 8.
2. MySQL Workbench.
3. Python 3.12 إصدار 64-bit.
4. Node.js 20.9 أو أحدث.
5. Visual Studio Code لفتح الكود، وهو اختياري لكنه مستحسن.
6. اتصال بالإنترنت في التشغيل الأول لتنزيل المكتبات.

يمكن التحقق من تثبيت Python وNode.js بفتح PowerShell وتنفيذ:

```powershell
python --version
node --version
npm --version
```

يمكن أيضاً التحقق من Python بواسطة:

```powershell
py --version
```

========================================
3. طريقة فتح الكود
==================

لفتح المشروع كاملاً باستخدام Visual Studio Code:

1. افتح Visual Studio Code.
2. اختر من القائمة:

```text
File → Open Folder
```

3. اختر المجلد التالي:

```text
المشروع الفصلي\الكود
```

بعد فتحه ستظهر المجلدات الرئيسية:

```text
backend
frontend
database
```

مسار كود الباك:

```text
المشروع الفصلي\الكود\backend\health_center_project
```

مسار كود الفرونت:

```text
المشروع الفصلي\الكود\frontend\next-project
```

مسار قاعدة البيانات:

```text
المشروع الفصلي\الكود\database\health_db.sql
```

========================================
4. استيراد قاعدة البيانات لأول مرة
==================================

تنفذ هذه الخطوة مرة واحدة فقط على جهاز الدكتور.

1. تأكد أن خدمة MySQL Server تعمل.
2. افتح MySQL Workbench.
3. افتح الاتصال المحلي:

```text
Local instance MySQL80
```

4. من القائمة العلوية اختر:

```text
Server → Data Import
```

5. اختر:

```text
Import from Self-Contained File
```

6. اضغط زر اختيار الملف، ثم حدد:

```text
المشروع الفصلي\الكود\database\health_db.sql
```

7. ملف قاعدة البيانات الحالي يحتوي على أمر إنشاء قاعدة `health_db` واستخدامها، لذلك لا حاجة لإنشاء الجداول يدوياً.
8. اضغط:

```text
Start Import
```

9. انتظر حتى تنتهي عملية الاستيراد بنجاح.
10. من قائمة `SCHEMAS` اضغط زر التحديث، ويجب أن تظهر قاعدة:

```text
health_db
```

إذا لم يظهر زر `Start Import`، كبّر نافذة MySQL Workbench أو أخفِ لوحة `Output` الموجودة في أسفل البرنامج.

إذا كانت توجد قاعدة بيانات قديمة باسم `health_db`، يجب أخذ نسخة احتياطية منها قبل استيراد النسخة الجديدة، وعدم استيراد الملف فوق قاعدة مهمة تحتوي على بيانات أخرى.

========================================
5. إعداد اتصال الباك بقاعدة MySQL
=================================

افتح الملف التالي باستخدام Visual Studio Code:

```text
المشروع الفصلي\الكود\backend\health_center_project\.env
```

لا تحذف إعدادات البريد أو `SECRET_KEY` الموجودة في الملف.

عدّل فقط معلومات الاتصال بقاعدة MySQL لتناسب جهاز الدكتور:

```env
DEBUG=True

DB_NAME=health_db
DB_USER=root
DB_PASSWORD=PUT_MYSQL_PASSWORD_HERE
DB_HOST=127.0.0.1
DB_PORT=3306
```

يجب استبدال:

```text
PUT_MYSQL_PASSWORD_HERE
```

بكلمة مرور مستخدم MySQL الموجودة على جهاز الدكتور.

مثال:

```env
DB_PASSWORD=MySQLPassword123
```

إذا لم تكن هناك كلمة مرور لمستخدم MySQL:

```env
DB_PASSWORD=
```

إذا احتوت كلمة المرور على فراغ أو الرمز `#`، توضع بين علامتي اقتباس مزدوجتين:

```env
DB_PASSWORD="My#Password 123"
```

بعد التعديل احفظ الملف بواسطة:

```text
Ctrl + S
```

إعدادات البريد الموجودة مسبقاً داخل `.env` لا تحتاج إلى تعديل، بشرط أن يكون البريد المستخدم بريداً تجريبياً وأن تكون كلمة المرور Gmail App Password وليست كلمة مرور Gmail العادية.

========================================
6. تشغيل الباك لأول مرة
=======================

1. افتح مجلد:

```text
المشروع الفصلي
```

2. اضغط بزر الفأرة الأيمن داخل مساحة فارغة.
3. اختر:

```text
Open in Terminal
```

4. داخل PowerShell انتقل إلى مجلد الباك:

```powershell
cd ".\الكود\backend\health_center_project"
```

5. أنشئ البيئة الافتراضية:

```powershell
py -3 -m venv venv
```

6. حدّث pip:

```powershell
.\venv\Scripts\python.exe -m pip install --upgrade pip
```

7. ثبّت مكتبات الباك:

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements.txt
```

8. طبّق migrations:

```powershell
.\venv\Scripts\python.exe manage.py migrate
```

9. شغّل الباك على المنفذ 8000:

```powershell
.\venv\Scripts\python.exe manage.py runserver 8000
```

عند ظهور الرسالة التالية يكون الباك قد اشتغل:

```text
Starting development server at http://127.0.0.1:8000/
```

يجب ترك نافذة PowerShell الخاصة بالباك مفتوحة طوال فترة استخدام النظام.

يمكن فتح الباك من:

```text
http://localhost:8000
```

ولوحة Django Admin من:

```text
http://localhost:8000/admin/
```

========================================
7. تشغيل الفرونت لأول مرة
=========================

افتح نافذة PowerShell ثانية من داخل مجلد:

```text
المشروع الفصلي
```

انتقل إلى مجلد الفرونت الحقيقي:

```powershell
cd ".\الكود\frontend\next-project"
```

ثبّت مكتبات الفرونت:

```powershell
npm ci
```

بعد انتهاء التثبيت شغّل الفرونت:

```powershell
npm run dev
```

عند ظهور عنوان التشغيل افتح المتصفح على:

```text
http://localhost:3000
```

صفحة تسجيل الدخول:

```text
http://localhost:3000/login
```

يجب ترك نافذة PowerShell الخاصة بالفرونت مفتوحة أثناء استخدام النظام.

الفرونت مضبوط مسبقاً ليتصل بالباك المحلي من خلال:

```text
http://localhost:8000
```

لذلك لا يحتاج الدكتور إلى تعديل أي ملف داخل كود الفرونت، ولا يحتاج المشروع إلى Render أو ngrok أو Aiven.

========================================
8. حسابات تجربة النظام
======================

الحسابات التالية موجودة في نسخة قاعدة البيانات `health_db.sql` المرفقة، ويمكن استخدامها لتجربة الأدوار المختلفة.

كلمات المرور حساسة لحالة الأحرف، لذلك يجب كتابتها تماماً كما هي:

| الدور              | اسم المستخدم       | كلمة المرور     |
| ------------------ | ------------------ | --------------- |
| المدير / Admin     | `ibraheem`         | `HI123123`      |
| موظف التوعية       | `amibrahimbarakat` | `HelloHello123` |
| موظف التسجيل       | `reg1`             | `Test@1234`     |
| موظف Help Desk     | `help1`            | `Test@1234`     |
| المستفيد / المستلم | `ben05`            | `Test@1234`     |

لتجربة أي حساب:

1. افتح:

```text
http://localhost:3000/login
```

2. أدخل اسم المستخدم وكلمة المرور.
3. اضغط زر تسجيل الدخول.
4. بعد الانتهاء سجّل الخروج قبل تجربة الدور التالي.

إذا بقيت بيانات الدور السابق ظاهرة، افتح نافذة تصفح خفي `Incognito` أو امسح بيانات الموقع ثم أعد تسجيل الدخول.

========================================
9. طريقة تجربة كل دور
=====================

أولاً: المدير

استخدم:

```text
Username: ibraheem
Password: HI123123
```

يمكن من خلال هذا الحساب تجربة لوحة المدير، عرض الإحصائيات، المستخدمين والوظائف الإدارية المتاحة.

يمكن أيضاً تجربة لوحة Django Admin من:

```text
http://localhost:8000/admin/
```

ثانياً: موظف التوعية

استخدم:

```text
Username: amibrahimbarakat
Password: HelloHello123
```

يمكن من خلال هذا الحساب تجربة وظائف التوعية مثل عرض وإدارة المقالات، البحث عن المستفيدين، المواعيد أو عمليات توزيع وتسليم المساعدات المتاحة في النظام.

ثالثاً: موظف التسجيل

استخدم:

```text
Username: reg1
Password: Test@1234
```

يمكن من خلال هذا الحساب تجربة تسجيل مستفيد جديد، إدخال البيانات الشخصية والصحية، رفع الصورة والبحث عن بيانات المستفيدين.

إذا كانت عملية التسجيل ترسل رسالة بريد إلكتروني، يجب أن يكون الجهاز متصلاً بالإنترنت وأن تكون إعدادات البريد الموجودة في `.env` صالحة.

رابعاً: موظف Help Desk

استخدم:

```text
Username: help1
Password: Test@1234
```

يمكن من خلال هذا الحساب تجربة عرض الشكاوى والطلبات والرد عليها ومتابعة حالتها.

خامساً: المستفيد أو المستلم

استخدم:

```text
Username: ben05
Password: Test@1234
```

يمكن من خلال هذا الحساب تجربة صفحة المستفيد وعرض بياناته وإشعاراته ومواعيده وشكاواه أو المساعدات الخاصة به.

========================================
10. تجربة الكاميرا والتعرف على الوجه
====================================

إذا كانت تجربة التعرف على الوجه أو تأكيد استلام المساعدة مطلوبة:

1. تأكد من وجود مجلد:

```text
المشروع الفصلي\الكود\backend\health_center_project\media
```

2. تأكد من وجود صور المستفيدين المطلوبة داخله.
3. افتح المشروع من:

```text
http://localhost:3000
```

4. عند طلب المتصفح صلاحية استخدام الكاميرا اختر:

```text
Allow
```

5. تأكد أن كاميرا الجهاز غير مستخدمة من برنامج آخر.

إذا تم منع الكاميرا، اضغط رمز القفل الموجود بجانب عنوان الموقع في المتصفح، ثم غيّر إذن الكاميرا إلى `Allow` وأعد تحميل الصفحة.

========================================
11. التشغيل في المرات اللاحقة
=============================

بعد تنفيذ التثبيت والاستيراد لأول مرة، لا يحتاج الدكتور إلى استيراد قاعدة البيانات أو تثبيت المكتبات مرة أخرى.

يجب فقط تشغيل MySQL ثم فتح نافذتي PowerShell.

في نافذة PowerShell الأولى شغّل الباك:

```powershell
cd ".\الكود\backend\health_center_project"
.\venv\Scripts\python.exe manage.py runserver 8000
```

في نافذة PowerShell الثانية شغّل الفرونت:

```powershell
cd ".\الكود\frontend\next-project"
npm run dev
```

بعد ذلك افتح:

```text
http://localhost:3000
```

يجب ترك النافذتين مفتوحتين طوال فترة استخدام النظام.

لإيقاف الباك أو الفرونت اضغط داخل نافذة PowerShell:

```text
Ctrl + C
```

13. معالجة الأخطاء المحتملة
===========================

إذا ظهر الخطأ:

```text
Access denied for user
```

يجب التأكد من القيم التالية داخل ملف `.env`:

```env
DB_USER=root
DB_PASSWORD=كلمة_مرور_MySQL
```

إذا ظهر:

```text
Unknown database 'health_db'
```

يجب استيراد ملف:

```text
المشروع الفصلي\الكود\database\health_db.sql
```

إذا ظهر:

```text
Can't connect to MySQL server
```

يجب تشغيل خدمة MySQL والتأكد أن المنفذ هو:

```text
3306
```

إذا ظهر أن الأمر `py` أو `python` غير معروف، يجب تثبيت Python 3.12 وإعادة فتح PowerShell.

إذا ظهر أن الأمر `npm` غير معروف، يجب تثبيت Node.js وإعادة تشغيل PowerShell أو الجهاز.

إذا ظهر خطأ بأن المنفذ 8000 مستخدم، أغلق نافذة الباك القديمة أو أوقفها بواسطة:

```text
Ctrl + C
```

إذا ظهر خطأ بأن المنفذ 3000 مستخدم، أغلق نافذة الفرونت القديمة ثم أعد تشغيل:

```powershell
npm run dev
```

إذا لم تظهر الصور، تأكد من إرسال مجلد `media` مع المشروع.

إذا لم تعمل الكاميرا، اسمح للمتصفح باستخدامها وأغلق أي برنامج آخر يستخدم الكاميرا.

إذا لم تصل رسالة البريد، تأكد من:

1. وجود اتصال بالإنترنت.
2. صحة إعدادات البريد داخل `.env`.
3. استخدام Gmail App Password.
4. عدم استخدام كلمة مرور Gmail العادية.

========================================
14. ملاحظات نهائية
==================

1. يجب تشغيل MySQL والباك والفرونت معاً.
2. يجب ترك نافذتي PowerShell مفتوحتين.
3. يتم استيراد قاعدة البيانات مرة واحدة فقط.
4. أمر `migrate` لا يحذف بيانات قاعدة البيانات.
5. لا يحتاج المشروع إلى Render أو ngrok أو Aiven.
6. روابط الفرونت مضبوطة مسبقاً على الباك المحلي `http://localhost:8000`.
7. لا يحتاج الدكتور إلى تعديل كود الفرونت.
8. التعديل الوحيد المطلوب غالباً هو وضع كلمة مرور MySQL الخاصة بجهاز الدكتور داخل `.env`.
9. يجب عدم حذف ملف `.env` أو مجلد `media` أو ملف `health_db.sql`.
10. حسابات التجربة السابقة موجودة في نسخة قاعدة البيانات المرفقة.
11. يجب كتابة أسماء المستخدمين وكلمات المرور بالحروف الكبيرة والصغيرة نفسها.
12. إذا كانت إعدادات البريد تحتوي حساباً شخصياً، يفضّل استبداله بحساب Gmail تجريبي قبل تسليم المشروع.
